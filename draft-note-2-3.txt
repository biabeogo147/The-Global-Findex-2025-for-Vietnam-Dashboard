On Page 5, the Save vs. Borrow Percentage visualization plots rates using a line chart layout across ordered income quintiles and income runway lengths.
Strict visualization theory states that continuous lines should only connect truly continuous, interval, or time-series data streams (t). Connecting discrete ordinal categories (like income quintiles from the poorest 20% to the richest 20%) with a line technically violates this rule, as it can imply intermediate data values between the points.
However, we deliberately chose to use line marks here to exploit the human brain's natural ability to track trends via Spatial Continuity. The line works as a visual vector that highlights the structural trajectory of financial behavior as income increases. It shows that saving rates rise steadily while borrowing rates decline. Using discrete bars instead of a line would clutter the chart and mask the clear, contrasting crossroads between these two financial strategies.
